# OSCA Replacement Index

Production Next.js app for exploring baseline automation exposure across all 1,156 Australian OSCA occupations.

## Run locally

```bash
nvm use
npm install
npm run dev
```

Open `http://localhost:3000`.

## Runtime

- Node `22.x`
- `.nvmrc` is checked in for local setup

## Environment

Copy `.env.example` if you want to use the OpenAI-powered `/api/generate` route:

```bash
cp .env.example .env.local
```

## Data sources in the app

- `src/data/oscaOccupations.json`: OSCA occupation structure, titles, skill levels, and hierarchy fields
- `src/data/oscaRoles.json`: OSCA occupation lead statements and descriptions
- `src/data/allScores.json`: precomputed AI replaceability scores
- `src/data/salaryMap.json`: annual salary estimates by occupation code

The home page builds the live index from those files on the server and renders:

- search, filtering, and sorting across all occupations
- shareable URL state for filters, sorting, pagination, and the open role modal
- score distribution and summary stats
- salary vs AI replacement economics
- industry exposure analysis across 19 ANZSIC divisions
- a detail modal for each occupation
- a methodology page with FAQ, glossary, sources, and caveats

## Public beta notes

- The current score dataset is frozen for the public beta.
- Scores are directional estimates, not forecasts of layoffs or policy outcomes.
- Salary and AI cost figures are comparison aids, not exact operating budgets.

## Rebuilding OSCA descriptions from raw XLSX

If you download fresh ABS source files into `data/raw`, regenerate `src/data/oscaRoles.json` once with:

```bash
npm run build:osca
```

Expected raw files:

- `data/raw/OSCA structure (1).xlsx`
- `data/raw/OSCA Category Descriptions.xlsx`

## Deploy
